
# CRUD Person – Admin Dashboard

A responsive full-stack **Person Management Admin Dashboard** built with **React.js** and **ASP.NET Web API**. The application connects a modern React frontend to a .NET backend, enabling users to manage person records through complete CRUD (Create, Read, Update, Delete) operations.

The project demonstrates frontend and backend integration, REST API communication, and structured data management in a full-stack web application.

## 🚀 Features

- **Responsive Admin Dashboard:** User-friendly interface designed for different screen sizes.
- **Create Records:** Add new person records through the dashboard.
- **View Records:** Retrieve and display person data.
- **Update Records:** Edit existing person information.
- **Delete Records:** Remove records when they are no longer needed.
- **REST API Integration:** Connect the React frontend with the ASP.NET Web API backend.
- **Component-Based Architecture:** Build reusable UI components with React.
- **Backend API:** Handle application requests and data operations through ASP.NET Web API.

## 🏗️ Application Architecture

The application follows a client-server architecture:

1. **React.js Frontend:** Provides the dashboard interface and handles user interactions.
2. **ASP.NET Web API:** Processes HTTP requests and handles CRUD operations.
3. **API Communication:** The frontend communicates with the backend through API requests.

```text
React.js Admin Dashboard
          |
          | HTTP Requests
          |
          v
    ASP.NET Web API
          |
          v
    Data Operations
```

## 📋 CRUD Operations

| Operation | Description |
|---|---|
| Create | Add a new person record |
| Read | Retrieve and display person records |
| Update | Modify existing person information |
| Delete | Remove a person record |

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js and npm
- .NET SDK compatible with the backend project
- Visual Studio or Visual Studio Code

### 1. Clone the Repository

```bash
git clone https://github.com/umairamjad2/CRUD-Person.git
```

### 2. Open the Project

Open the cloned repository in your preferred code editor.

### 3. Configure the Backend

Open the ASP.NET Web API project in Visual Studio or your preferred .NET development environment.

Configure any required application settings and database connection details according to the backend configuration.

Run the API using the project's configured startup profile.

### 4. Configure the Frontend

Navigate to the React application directory, then install its dependencies:

```bash
npm install
```

Configure the API base URL to point to your running ASP.NET Web API.

### 5. Start the Frontend

Run the development command configured in the frontend's `package.json`, for example:

```bash
npm run dev
```

If the project uses a different development script, use the corresponding command from `package.json`.
